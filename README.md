## Featured project

### [DeepNoise](https://github.com/n3w3r4/DeepNoise)

An open-source Windows app that reduces microphone and incoming call noise using neural audio processing.

- DeepFilterNet3 noise suppression and WebRTC AEC3 echo cancellation.
- Python audio engine with a WebView2 interface through pywebview.
- System tray controls, virtual microphone support and automated tests that run without audio hardware.

**Stack:** Python · DeepFilterNet3 · WebView2 · Windows audio  
**Status:** Preview — hardware compatibility is still being validated.

[Explore the repository →](https://github.com/n3w3r4/DeepNoise)

## Projeto em destaque

### [DeepNoise](https://github.com/n3w3r4/DeepNoise)

Aplicativo open source para Windows que reduz ruídos do microfone e do áudio recebido em chamadas usando processamento neural de áudio.

- Supressão de ruídos com DeepFilterNet3 e cancelamento de eco com WebRTC AEC3.
- Motor de áudio em Python com interface WebView2 via pywebview.
- Controles na bandeja do sistema, suporte a microfone virtual e testes automatizados que executam sem hardware de áudio.

**Stack:** Python · DeepFilterNet3 · WebView2 · Áudio no Windows  
**Status:** Preview — compatibilidade com diferentes dispositivos ainda em validação.
